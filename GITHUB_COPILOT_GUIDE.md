# Как проверить подключение GitHub Copilot к Visual Studio

Это руководство поможет вам проверить, что GitHub Copilot правильно подключен к вашей среде разработки.

## Для Visual Studio Code

### 1. Проверка установки расширения

1. Откройте Visual Studio Code
2. Нажмите на иконку расширений в левой боковой панели (или нажмите `Ctrl+Shift+X` / `Cmd+Shift+X`)
3. В поиске введите "GitHub Copilot"
4. Убедитесь, что расширение **GitHub Copilot** установлено и включено

### 2. Проверка статуса подключения

1. В правом нижнем углу VS Code найдите иконку GitHub Copilot (выглядит как логотип Copilot)
2. Статусы иконки:
   - ✅ **Иконка активна** (белая или цветная) - Copilot подключен и работает
   - ❌ **Иконка неактивна** (серая с красным крестом) - Copilot отключен или есть проблемы
   - ⚠️ **Иконка с предупреждением** - требуется действие (например, вход в аккаунт)

3. Нажмите на иконку Copilot, чтобы увидеть меню с опциями:
   - "Enable Completions" / "Disable Completions" - включить/отключить автодополнение
   - "Check status" - проверить статус
   - "Sign in" - войти в GitHub (если не авторизованы)

### 3. Тест в реальном коде

1. Создайте новый файл (например, `test.js` или `test.py`)
2. Начните писать комментарий с описанием функции:
   ```javascript
   // функция для сложения двух чисел
   ```
3. Нажмите Enter и начните писать `function`
4. Если Copilot работает, вы увидите серые подсказки с предложениями кода
5. Нажмите `Tab`, чтобы принять предложение

### 4. Проверка через командную палитру

1. Откройте командную палитру (`Ctrl+Shift+P` / `Cmd+Shift+P`)
2. Введите "Copilot"
3. Вы должны увидеть команды GitHub Copilot:
   - "GitHub Copilot: Enable"
   - "GitHub Copilot: Disable"
   - "GitHub Copilot: Sign In"
   - "GitHub Copilot: Check Status"

## Для Visual Studio (2022)

### 1. Проверка установки расширения

1. Откройте Visual Studio 2022
2. Перейдите в меню **Extensions** → **Manage Extensions**
3. В разделе "Installed" найдите **GitHub Copilot**
4. Убедитесь, что расширение установлено и включено

### 2. Проверка статуса авторизации

1. В правом верхнем углу найдите иконку профиля
2. Нажмите на неё и проверьте, что вы авторизованы в GitHub
3. Убедитесь, что ваш аккаунт GitHub имеет доступ к GitHub Copilot

### 3. Проверка в меню Tools

1. Откройте меню **Tools** → **Options**
2. В левой панели найдите **GitHub** → **Copilot**
3. Убедитесь, что Copilot включен
4. Проверьте настройки автодополнения

### 4. Тест в реальном коде

1. Создайте новый файл кода (C#, Python, JavaScript и т.д.)
2. Начните писать комментарий:
   ```csharp
   // метод для вычисления факториала числа
   ```
3. Нажмите Enter и начните писать объявление метода
4. Если Copilot работает, вы увидите полупрозрачные предложения кода
5. Нажмите `Tab`, чтобы принять предложение

### 5. Проверка статуса в строке состояния

1. В нижней части окна Visual Studio найдите статус GitHub Copilot
2. Если иконка показывает галочку или логотип - Copilot активен
3. Если есть предупреждение - кликните, чтобы узнать детали

## Общие проблемы и решения

### Проблема: Copilot не предлагает код

**Возможные решения:**
1. Проверьте, что вы авторизованы в GitHub
2. Убедитесь, что у вас есть активная подписка GitHub Copilot
3. Перезапустите IDE
4. Проверьте подключение к интернету
5. Попробуйте отключить и снова включить Copilot

### Проблема: Иконка Copilot серая или с ошибкой

**Возможные решения:**
1. Нажмите на иконку и выберите "Sign In" для входа в GitHub
2. Проверьте, что у вас есть действующая подписка Copilot
3. Обновите расширение до последней версии
4. Проверьте логи: View → Output → GitHub Copilot

### Проблема: Нет расширения в списке

**Возможные решения:**
1. Установите расширение из маркетплейса:
   - VS Code: https://marketplace.visualstudio.com/items?itemName=GitHub.copilot
   - Visual Studio: Extensions → Manage Extensions → Online → поиск "GitHub Copilot"
2. Перезапустите IDE после установки

## Проверка подписки

1. Перейдите на https://github.com/settings/copilot
2. Проверьте статус вашей подписки
3. Убедитесь, что:
   - Подписка активна
   - Не истёк пробный период (если используется)
   - Организация предоставила вам доступ (для корпоративных аккаунтов)

## Полезные команды

### VS Code
- `Ctrl+Enter` / `Cmd+Enter` - открыть панель с несколькими предложениями Copilot
- `Alt+]` / `Option+]` - следующее предложение
- `Alt+[` / `Option+[` - предыдущее предложение
- `Tab` - принять предложение
- `Esc` - отклонить предложение

### Visual Studio
- `Alt+/` - показать предложения Copilot
- `Tab` - принять предложение
- `Esc` - отклонить предложение

---

**Примечание:** Для работы GitHub Copilot требуется активная подписка. Студенты, преподаватели и мантейнеры популярных open-source проектов могут получить бесплатный доступ.
